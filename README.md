# Password Generator
Project Name: Simple Password Generator                                                                                                                               
What it does:
This project is a Python program that helps users create strong and secure passwords.
* The user can choose how long the password should be (for example: 8, 12, or 16 characters).
* The user can choose what to include: capital letters (A-Z), small letters (a-z), numbers (0-9), and symbols (like @, #, $).
* The program picks characters completely at random so that no one can easily guess or hack the password.
